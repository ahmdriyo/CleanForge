1. Tujuan Tantangan (The Challenge)
   Peserta ditantang untuk membangun sebuah aplikasi web berbasis AI yang disebut "Personal Gemini Journal" dan mende-deploy aplikasi tersebut agar berjalan secara live di Google Cloud Run.

2. Persyaratan Teknis Dasar
   Panitia telah menyediakan template atau panduan dasar (starter app) di Google AI Studio. Namun, peserta diwajibkan untuk membangun aplikasi dengan arsitektur yang memenuhi 4 pilar utama:

Autentikasi Pengguna (User Identity): Aplikasi harus memiliki fitur login pengguna yang aman menggunakan Firebase Auth.

Integrasi AI: Aplikasi harus menggunakan Gemini API untuk melakukan percakapan multi-turn (brainstorming, refleksi, pembuatan jurnal).

Penyimpanan Data Privat (Backend Database): Interaksi pengguna dengan Gemini harus disimpan secara private untuk masing-masing pengguna menggunakan Cloud Firestore (mencegah kebocoran data antar pengguna).

Keamanan Rahasia (Secrets): API keys dan data rahasia tidak boleh di-hardcode, melainkan harus ditarik secara aman menggunakan Google Cloud Secret Manager.

3. Tantangan Sebenarnya (Inovasi & Autentisitas)
   Rohan sangat menekankan bahwa peserta tidak akan mendapatkan nilai bagus jika hanya mengumpulkan aplikasi dasar sesuai template. Tantangan utamanya adalah berinovasi dan berkreasi (Make it Yours). Peserta diharapkan untuk:

Mengembangkan aplikasi lebih jauh dengan menambahkan fitur unik.

Mengintegrasikan API pihak ketiga (misalnya: Google Maps untuk geo-tagging jurnal, atau Slack/Email untuk notifikasi pengingat menulis jurnal).

Membangun UI/UX yang imersif dan orisinal sesuai dengan interpretasi masing-masing developer terhadap kebutuhan pengguna (misal: jurnal khusus untuk profesional yang sedang rentan terhadap burnout).

4. Kriteria Penilaian
   Karya para peserta akan dinilai berdasarkan 4 kriteria:

Autentisitas: Apakah aplikasi tersebut orisinal atau hanya menyalin starter app?

Usability (Kegunaan): Apakah pengalaman pengguna (UX) lancar dan navigasinya mudah?

Stabilitas: Apakah aplikasi stabil dan mampu menangani error (error handling) tanpa mengalami crash?

Keamanan: Apakah sistem autentikasinya bekerja dengan benar dan tidak ada API key rahasia yang terekspos?

5. Syarat Pengumpulan (Deliverables)
   Untuk menyelesaikan tantangan ini dan memenuhi syarat kompetisi, peserta wajib mengumpulkan 3 hal utama melalui platform Hack2skill:

Link Aplikasi Live / Video Walkthrough: Tautan ke aplikasi yang sudah di-deploy di Cloud Run, atau video demo jika aplikasi tidak bisa diakses publik.

Repositori Kode (Public): Tautan GitHub/GitLab publik yang mencakup kode frontend, backend, konfigurasi keamanan Firestore, dan file README yang jelas tentang cara menjalankannya.

Postingan Media Sosial: Membagikan karya mereka di platform seperti LinkedIn, X (Twitter), atau Medium dengan menceritakan apa yang dibangun beserta hashtag #AccelerateAIwithCloudRun.

Ideathon Challenge

Build a Secure "Personal Gemini Journal"

Most AI-generated apps look great in a demo and fall apart in production — hardcoded keys, no auth boundaries, shared databases with zero isolation. Your challenge is to fix that at the source.

Before you write a line of code, configure Google AI Studio to think like a security engineer — baking threat modeling, secure coding standards, database isolation, and proper secret management into its custom instructions. That becomes your studio's constitution for everything you build next.

Then use it to build the Personal Gemini Journal: an authenticated web app where users sign in, journal or brainstorm with Gemini, and have their conversations saved to their own private space.

Your build must include:
User authentication — sign-in via Firebase

Multi-turn AI interaction — real, ongoing conversations with the Gemini API

Isolated data storage — each user's logs in Cloud Firestore, with zero cross-user leakage

Secure key management — API keys via Google Cloud Secret Manager, never hardcoded

Plus at least one original feature enhancement of your own, built using AI Studio, that goes beyond the base spec.
